# Akses Digital by ZY

Selamat datang di **Akses Digital by ZY**.

Repositori ini berisi kumpulan panduan, dokumentasi, proyek open-source, dan sumber belajar seputar:

- 📱 Android
- 💻 Termux
- 🐧 Linux
- 🌿 Git & GitHub
- 💡 Pemrograman
- ⚙️ Otomatisasi
- 🔐 Keamanan Siber

## Tujuan

Repositori ini dibuat untuk membantu pemula maupun pengembang dalam mempelajari teknologi digital melalui materi yang terstruktur, mudah dipahami, dan dapat dipraktikkan secara langsung.

## Isi Repositori

- Tutorial langkah demi langkah
- Dokumentasi dan referensi
- Contoh proyek
- Script dan tools open-source
- Tips dan praktik terbaik
