# ⚙️ Instalasi

Clone repositori:

```bash
git clone https://github.com/USERNAME/Akses-digital-by-zyy.git
```

Masuk ke folder:

```bash
cd Akses-digital-by-zyy
```

Jika menggunakan Termux, pastikan Git sudah terpasang:

```bash
pkg update && pkg upgrade -y
pkg install git -y
```
